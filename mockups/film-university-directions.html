Today's exercise · Writing · 20 min

Find the turn

Take any scene you've written. Write one sentence for where it starts and one for where it ends. If they're the same sentence, the scene isn't done yet.

Pick a scene, any length.
Write the start state in one sentence.
Write the end state in one sentence.
Rewrite until they differ. Keep the old version.
