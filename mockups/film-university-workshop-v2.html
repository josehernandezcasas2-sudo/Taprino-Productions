Workshop — three ways to make the home page better

Same data as the version that just shipped (today's exercise, exercises with the lessons that teach them, topics, templates). Each direction changes what the page emphasises and how far you scroll. Shown with the full sample catalogue (10 exercises, 20 lessons, 6 templates), desktop then phone.

A

Hero + shelves — one big thing, then rails by topic

Today's exercise becomes a full-width hero with the lesson video as its right half. Topics turn into a pill strip (not six cards). Exercises are horizontal shelves per topic, so the page is wide instead of tall, and the templates shelf gets real covers in a rail. Roughly half the scroll of today's page.

Today's exercise · Writing · 20 min

Find the turn

Take any scene you've written. Write one sentence for where it starts and one for where it ends. If they're the same sentence, the scene isn't done yet.

  1. Pick a scene, any length.
  2. Write the start state in one sentence.
  3. Write the end state in one sentence.
  4. Rewrite until they differ. Keep the old version.

B

The desk — today pinned on the left, the catalogue as a list on the right

Two columns. Left stays put while you scroll: today's exercise (compact) and the topic list with counts, which doubles as the filter. Right is every exercise as a row with its lesson thumbnail, grouped under topic headings, so 20 or 40 exercises stay scannable. Templates become a row list too. Densest of the three; reads like a workbook index.

C

The week — your seven days, then what's next for you

Leans on the "I did it" state that's already stored on the device. A seven-day strip shows what you did and today's slot; below it, "Up next for you" is three exercises you haven't done, then the full catalogue as a path with done items faded. No sign-in needed; it just reads the device's done list. Strongest habit pull, and the only one that changes when you come back tomorrow.
